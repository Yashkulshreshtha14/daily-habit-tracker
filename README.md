# Little by Little — Daily Habit Tracker

A clean, responsive habit tracker that helps you focus on small daily wins. Built with plain HTML, CSS, and JavaScript — no install or build step required.

## Features

- Add habits with a name and emoji icon
- Mark habits complete and see your daily progress
- Automatically reset completion marks when a new day begins
- Save habits in your browser with `localStorage`
- Remove habits you no longer want to track
- Responsive layout for phones and desktops

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Deploy with GitHub Pages

1. Push the files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your main branch and the root folder, then save.

GitHub Pages will publish the app at the URL shown in the Pages settings.
